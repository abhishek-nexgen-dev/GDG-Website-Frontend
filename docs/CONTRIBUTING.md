# Contributing to GDG Ranchi Frontend

First off, thank you for considering contributing to the GDG Ranchi Frontend project! We welcome contributions from the community to help make our platform better for everyone.

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally.
3. **Install dependencies** using `npm install`.
4. **Create a new branch** for your feature or bug fix: `git checkout -b feature/your-feature-name`.

## Development Workflow

1. Start the development server using `npm run dev`.
2. Make your changes in your feature branch.
3. Keep your code clean, readable, and properly indented.
4. If you add new components, ensure they are responsive and accessible.
5. Use `npm run lint` to check for code style issues and fix them before committing.

## Pull Request Process

1. Commit your changes with a clear and descriptive commit message.
2. Push your branch to your forked repository on GitHub.
3. Create a Pull Request against the `main` branch of the original repository.
4. Provide a detailed description of your changes in the PR description, including the problem you're solving and how you tested the changes.
5. Wait for a maintainer to review your code. You might be asked to make some adjustments.

## Reporting Bugs

If you find a bug, please create an issue on GitHub with:
- A clear description of the problem.
- Steps to reproduce the bug.
- The browser and operating system you're using.
- Screenshots if applicable.

We appreciate your support in making GDG Ranchi the best community platform!
